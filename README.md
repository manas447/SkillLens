# 🧠 SkillLens — Explainable AI for Employability Analysis

SkillLens is an explainable AI-based decision support system that evaluates student employability, provides confidence-based scoring, and highlights skill gaps with actionable recommendations.

---

## 🚀 Features
- Employability score (0–100%)
- Confidence level (Low / Medium / High)
- Skill gap identification
- Role-based evaluation (ML Intern, Backend Intern, Data Analyst)
- Explainable predictions (not black-box AI)
- Flask REST API + Web UI

---

## 🧠 Tech Stack
- Python
- Scikit-learn
- Flask
- HTML, CSS, JavaScript
